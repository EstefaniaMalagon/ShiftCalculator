# Shift Calculator

Aplicación móvil multiplataforma que permite a los trabajadores registrar su jornada laboral y calcular automáticamente el valor estimado de su salario, incluyendo horas extras y recargos legales según la ley.

## Ejecutar la App

### En el navegador web
npx expo start --web

Se abre automáticamente en Chrome en http://localhost:8081

### En celular con Expo Go
npx expo start --clear

Escanea el QR con la app Expo Go.

### En emulador Android (requiere Android Studio)
npx expo start --clear

Luego presiona la tecla 'a' en la terminal

### En simulador iOS (solo Mac)
npx expo start --clear

Luego presiona la tecla 'i' en la terminal
